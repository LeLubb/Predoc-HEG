# Report structure and notebook preparation

## Files

- `main_code_V4.ipynb`: original analysis, code and saved outputs unchanged. Do not rerun or overwrite it to build this report.
- `find_relevant_df.ipynb`: retain the original setup, data preparation and CSV export code. Add short Markdown headings; remove the subsequent exploratory inventory, first-measurement and station-count checks, which do not feed the figures.
- `figures/`: all 18 PNG images decoded directly from the saved notebook outputs, without cropping, redrawing or recompression.
- `main.tex`: brief English report using these images and their saved station counts.
- `main.pdf`: compiled report.
